本版把子代理的记录做成一块面板，工作台的标签条可以滚动，项目可以带一个标记；「全部放行」一次问清并连沙箱一起动；会话变长时，会告诉你它已经花了多少。

## 新增

- 窗口上的子代理徽章打开一块看板，按每次运行列出它的记录：做了几步、用了多少 token、交给它的任务原文；已经结束的运行留着它是怎么结束的，任务太长时可以展开 (79539412a)
- 工作台的标签条可以滚动，「在跑」和「已结束」不再挤成一行 (67aaa640c)
- 项目可以带一个标记：图标与颜色存在本机，跟着侧栏的折叠状态走 (bc9361e06)
- 「全部放行」一次问清：不再逐次询问，bash 同时离开沙箱。两半一起动，因为少了任何一半，它承诺的「什么都读得到、什么都不拦」就不成立 (a8e30e048)
- 输入框会记住上个会话用的是哪个模型，新窗口从那里开始 (1350b2a3f)
- 工具卡片里的命令可以一键复制 (1350b2a3f)
- 会话变长时会提示：模型已经为它读过多少遍满窗历史，并建议开一个新会话 (19883c5f2)

## 变更

- 后台任务的「已开始／已结束」不再占据对话流：那是机器的事，任务列表已经写着；失败仍然留在对话里 (4a0e03618)
- 设置里的每一组可以按标题折叠，侧栏的工具单占一列 (ca238f695)
- 运行中的子代理在徽章旁说出自己在运行，不必再猜 (f437a54fe)
- 运行中的工具行改说界面语言，英文界面不再读到中文 (9836d91c9)
- 关闭窗口或退出时，若还有后台任务在跑，会先问一句；留下来就能拿回窗口 (7ce21daf2)

## 修复

- 展开的计划列表可以从标题行收起，不必再去找那个小图标 (f5868fce2)
- 早先进程留下的、标记为运行中却无人执行的子代理，会在新进程里被中断，而不是让窗口一直等一个永远不会回答的运行 (c198b9e38)
- 模型调用的首字节等待放宽：预填充大上下文时的长时间沉默不再被当作停滞，并反复重试到同一堵墙 (1280cdd4e)
- macOS 包带上机器能接受的签名；此前安装器会把它读成「已损坏」并拒绝 (a0ed3bdc0)

## 升级须知

- 后台任务的开始与结束不再在对话里留下卡片；在跑和已结束的任务仍可在任务列表与工作台标签里看到 (4a0e03618)
- 「全部放行」现在会同时关掉沙箱；单独设置沙箱的选项仍然有效 (a8e30e048)

This release turns a sub-agent's record into one panel, scrolls the workbench tab strip, and lets a project carry a mark. "Allow everything" asks once and takes the sandbox with it. A conversation that has grown long now says what it has already cost.

## New

- The sub-agent badge in the window chrome opens a panel per run: its steps, its tokens and the task it was handed; an ended run keeps how it ended, and a task longer than its line folds open (79539412a)
- The workbench tab strip scrolls, so "running" and "ended" no longer crowd into one row (67aaa640c)
- A project can carry a mark: the glyph and the colour live on this machine, beside the sidebar's folded folders (bc9361e06)
- "Allow everything" asks once: no more per-call questions, and bash leaves the sandbox in the same move — both halves together, because either alone leaves its promise untrue (a8e30e048)
- The composer remembers the model the last conversation here ended on, and a new window starts there (1350b2a3f)
- A command in a tool card copies with one click (1350b2a3f)
- A conversation that has grown long says how many windows of history the model has read for it, and suggests a new one (19883c5f2)

## Changed

- A background job's start and its end no longer take a turn in the conversation: that is the machine's business, and the job list already says it; a failure stays (4a0e03618)
- Each settings group folds from its own heading, and the tools rail stands in a column of its own (ca238f695)
- A running sub-agent says what it is doing beside the badge (f437a54fe)
- The running tool rows speak the interface's language, so an English window no longer reads them in Chinese (9836d91c9)
- Closing the window or quitting asks first while a background job is still running; staying gets the window back (7ce21daf2)

## Fixed

- The open plan list closes from its own heading, instead of only from the small icon (f5868fce2)
- A sub-agent an earlier process left marked running is interrupted, instead of leaving a window polling a run that can never answer (c198b9e38)
- A model call waits longer for its first byte: a large prefill's silence is no longer read as a stall and retried into the same wall (1280cdd4e)
- A macOS bundle carries a signature the machine accepts; the installer used to read it as damaged and refuse it (a0ed3bdc0)

## Upgrade notes

- A background job's start and end no longer leave cards in the conversation; running and ended jobs remain visible in the job list and the workbench tab (4a0e03618)
- "Allow everything" now turns the sandbox off with it; the separate sandbox setting still applies (a8e30e048)
