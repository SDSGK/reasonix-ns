本版加入子代理独立对话：切到子代理的视图后可以继续给它派活；发布与更新通道迁到本仓库，软件不再向任何外部服务发送数据。

## 新增

- 切到某个子代理的视图后，输入框会切到该子代理的上下文；在那里发消息是让它接着做，而不是新开一个子代理 (57c779048)
- 窗口标题栏上的子代理徽章可以打开浮层面板，列出本会话的子代理 (390360048)
- 前台调用改为先作为后台任务启动，并在 5 秒的同步窗口里等待；窗口内结束的结果与直接执行无异，超过窗口则先返回任务编号，完成结果并入之后的对话 (390360048)

## 变更

- 子代理完成时会收到通知，不必切到它的视图才知道它做完了 (489815c5f)
- 交付卡片和子代理栏可以一直留在会话里，切走再切回来仍然在 (71ab00a41)
- 崩溃报告、匿名统计和反馈不再发往任何服务器，扩展市场也不再连接默认地址；这些通道默认关闭，配置之后才会启用 (c1e8ad4ae)

## 修复

- 子代理栏会显示已经结束的子代理，而不是把它们藏起来 (c6aa795ed)

## 移除

- 移除软件内的赞助入口、作者署名和社区链接 (57c779048)

## 升级须知

- 更新检查改为从本仓库的 GitHub Release 获取，版本目录与清单都随该仓库的发布走；旧版本升级时客户端会按新地址查找新版本 (c1e8ad4ae)
- macOS 包未做 Developer ID 签名时不能自动更新，需要手动下载替换；每次发布的说明里会写明本次是否签名 (175c1a423)

This release adds sub-agent chat: a message sent in a sub-agent's view continues its work. The release and update channels move to this repository, and the app sends no data to any outside service.

## New

- Switching to a sub-agent's view switches the composer to that sub-agent's context; a message sent there continues its work instead of starting a new sub-agent (57c779048)
- The sub-agent badge in the window chrome opens a floating panel listing the session's sub-agents (390360048)
- A foreground call now starts as a background job and waits in a 5-second sync window; a call that settles inside the window returns exactly like a direct run, and one that runs past it hands back the job id, with its completion folded into later turns (390360048)

## Changed

- A finished sub-agent raises a notice, so there is no need to switch to its view to learn that it is done (489815c5f)
- The delivery card and the delegate rail stay in the conversation across a switch away and back (71ab00a41)
- Crash reports, anonymous statistics and feedback reach no server, and the extension market no longer connects to a default address; these channels are off until one is configured (c1e8ad4ae)

## Fixed

- The delegate rail shows finished delegates instead of hiding them (c6aa795ed)

## Removed

- The in-app sponsor entry, the author's line and the community links are removed (57c779048)

## Upgrade notes

- Update checks now read this repository's GitHub releases, and the version catalog and the manifest travel with them; a client upgrading from an older build looks for the new version at the new address (c1e8ad4ae)
- A macOS package without a Developer ID signature cannot update itself and has to be replaced by hand; each release's notes say whether it was signed (175c1a423)
